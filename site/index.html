Fantasy console · Spec v0.3

The handheld that never shipped. Carts are WebAssembly.

WASM-AD is an open standard for a 240×160 console with Game Boy Advance–style hardware. A cart is one .wasm file that draws and plays sound by writing registers and memory, in any language that compiles to WebAssembly.

Hardware

GBA-era specs, bit for bit

Palettes, tiles, maps and sprite attributes use the Game Boy Advance's own formats, so decades of documentation and tools still apply.

240×160pixels at 60 frames per second
32,768colors, RGB555, in 16+16 palette banks
4tile layers, two that rotate and scale, or a bitmap mode
128sprites, 8×8 up to 64×64, with 32 rotation matrices
6sound channels: square, wave, noise and 8-bit samples
αalpha blending, fades, windows, mosaic, per-line raster effects
4players, each on a controller of their own
32 KBbattery-backed save RAM

How it works

The hardware is memory

There is no drawing API. A cart writes tiles, maps, palettes and sprites into fixed addresses of its own linear memory, laid out like the GBA's. Sixty times a second the console calls update() and turns that memory into a frame.

0x00000null page
0x00400I/O registers
0x00800palettes
0x00C00OAM · sprites
0x01000VRAM · 96 KB of tiles, maps and bitmaps
0x19000save RAM
0x21000sample RAM
0x28000your cart's code, data, stack, heap →

Any language

Rust, Zig, C, AssemblyScript, Go: if it compiles to wasm and can write to an address, it can make a cart. No bindings needed.

Save states for free

All state lives in linear memory, sound included. Save states and replays are files any host can load, and rewind is a snapshot ring: hold ⌫ while playing.

Deterministic

No clock, no random syscalls: one boot seed plus the inputs fully determine a run. Netplay and golden-image tests just work.

One file

Code, art and metadata ship in a single .wasm, at most 32 MiB, like a cartridge. One import: trace.

Get started

A cart in twenty lines, in your language

SDKs for Rust, C and C++, Zig, AssemblyScript and Go wrap the registers under the spec’s names. Each ships the same starter cart, and all of them render it identically, frame for frame.

use wasm_ad::*;

wasm_ad::cart! { title: "My Cart", author: "me" }

#[unsafe(no_mangle)]
pub extern "C" fn start() {
    bg_palette()[0] = rgb(40, 60, 160);  // backdrop
    obj_palette()[1] = rgb(255, 216, 64);
    obj_tiles()[0] = [0x11; 32];         // a solid 8×8 tile
    reg::DISPCNT.write(dispcnt::MODE0 | dispcnt::OBJ | dispcnt::OBJ_1D);
}

#[unsafe(no_mangle)]
pub extern "C" fn update() {
    let x = (frame() % 240) as i32;
    oam::set(0, Sprite::new(x, 76, SpriteSize::S8x8, 0));
}

#include "wasm_ad.h"

WAD_CART(WAD_TITLE("My Cart") WAD_AUTHOR("me"));

WAD_EXPORT(start) void start(void) {
    wad_bg_palette[0] = wad_rgb(40, 60, 160);  /* backdrop */
    wad_obj_palette[1] = wad_rgb(255, 216, 64);
    for (int i = 0; i < 32; i++) wad_obj_tiles[0][i] = 0x11;
    WAD_DISPCNT = WAD_MODE0 | WAD_DISP_OBJ | WAD_OBJ_1D;
}

WAD_EXPORT(update) void update(void) {
    int32_t x = (int32_t)(wad_frame() % 240);
    wad_oam_set(0, wad_sprite_new(x, 76, WAD_S8x8, 0));
}

import { write16, reg, dispcnt, rgb, setBgColor, setObjColor, objTile,
         fillTile, frame, oam, sprite, SpriteSize } from "@raskell/wasm-ad/assembly";

export function start(): void {
  setBgColor(0, rgb(40, 60, 160));   // backdrop
  setObjColor(1, rgb(255, 216, 64));
  fillTile(objTile(0), 0x11);        // a solid 8×8 tile
  write16(reg.DISPCNT, dispcnt.MODE0 | dispcnt.OBJ | dispcnt.OBJ_1D);
}

export function update(): void {
  const x = <i32>(frame() % 240);
  oam.set(0, sprite.make(x, 76, SpriteSize.S8x8, 0));
}

package main

import ad "github.com/raskell-io/wasm-ad/sdk/tinygo"

//export start
func start() {
	ad.BGPalette()[0] = ad.RGB(40, 60, 160) // backdrop
	ad.ObjPalette()[1] = ad.RGB(255, 216, 64)
	for i := range ad.ObjTiles()[0] {
		ad.ObjTiles()[0][i] = 0x11 // a solid 8×8 tile
	}
	ad.DISPCNT.Write(ad.Mode0 | ad.DispObj | ad.Obj1D)
}

//export update
func update() {
	x := int32(ad.Frame() % 240)
	ad.OAMSet(0, ad.NewSprite(x, 76, ad.S8x8, 0))
}

func main() {}
